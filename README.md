# Password Brute Force Experiment

Учебно-исследовательский проект для воспроизводимого сравнения масочного перебора SHA-1 с Hashcat на локально подготовленных данных. Проект не предназначен для доступа к чужим системам. Исходные базы и восстановленные пароли не должны публиковаться.

## Требования

- Python 3.10+;
- Hashcat, установленный отдельно;
- NVIDIA GPU/драйвер, если выполняется реальный запуск;
- локальные текстовые файлы UTF-8 в `data/source/` или `data/samples/`.

Зависимости внешних Python-пакетов отсутствуют: используется стандартная библиотека.

## Настройка

1. Установите Hashcat и проверьте `hashcat --version`.
2. Поместите легально полученные наборы паролей в `data/source/`.
3. Поместите четыре утверждённых файла `.hcmask` в `data/masks/` и укажите их в `experiment.mask_files`. Каждый файл считается одной экспериментальной маской. Внутри smart-файла может быть несколько строк с пользовательскими наборами и разными длинами.
4. При необходимости измените `config/config.json`, прежде всего `hashcat.executable`, `experiment.mask_file`, кодировку и пути.

Поддерживается синтаксис Hashcat `.hcmask`: обычная маска и строки с пользовательскими наборами, например `?d?l?u,?d?l,?1?2?2?a`. Hashcat получает каждый файл целиком. Для всех файлов по умолчанию включён диапазон `--increment --increment-min 4 --increment-max 12`; параметры задаются в `experiment.increment`. Подсчёт суммирует пространство строк одного файла и помечает неподдержанные конструкции как неточные, а не подменяет их оценкой.

## Команды

Проверка окружения без Hashcat-перебора:

```text
python main.py --check
```

Полный конвейер:

```text
python main.py
```

Отдельные этапы:

```text
python scripts/01_generate_hashes.py
python scripts/02_merge_hashes.py
python scripts/03_count_combinations.py
python scripts/04_run_hashcat.py
python scripts/05_analyze_results.py
python scripts/06_password_statistics.py
python scripts/07_compare_results.py
python scripts/08_export_report.py
```

Проверка формирования каталогов запуска Hashcat без выполнения:

```text
python scripts/04_run_hashcat.py --dry-run
```

Все скрипты поддерживают `--help` и `--config путь/к/config.json`. Повторный запуск Hashcat получает новый идентификатор эксперимента и не перезаписывает предыдущие результаты.

## Этапы и результаты

- `01_generate_hashes.py` — потоковый SHA-1, отдельные `.txt` и локальные `mapping.jsonl`.
- `02_merge_hashes.py` — строгая проверка SHA-1 и дедупликация по значению.
- `03_count_combinations.py` — `results/statistics/combination_counts.json/csv`, одна запись на файл `.hcmask`.
- `04_run_hashcat.py` — последовательный запуск четырёх файлов, изолированный potfile, stdout/stderr, метаданные и статусы в `results/raw/<experiment>/`.
- `05_analyze_results.py` — `results/processed/experiment_results.json/csv`.
- `06_password_statistics.py` — статистика и обезличенный `top_100.csv`.
- `07_compare_results.py` — `results/comparisons/mask_comparison.json/csv`.
- `08_export_report.py` — `results/reports/final_report.md`.

В отчёт попадают только числовые показатели и характеристики. Сопоставление пароль→хеш хранится локально и исключено из Git.

## Методика и ограничения

Время измеряется непосредственно Python от запуска процесса до завершения. Теоретическое время полного пространства вычисляется как `N / V` только при наличии фактической скорости Hashcat. Завершившийся ранее процесс не следует считать полным перебором всей маски. Последующие маски получают только ещё не найденные хеши, поэтому отчёт разделяет новые и накопленные находки.

SHA-1 не предназначен для современного хранения паролей; результаты нельзя переносить на Argon2id, scrypt, bcrypt или PBKDF2. Маска не покрывает все возможные строки, поэтому отсутствие находки означает только отсутствие результата в заданном пространстве.

Перед работой с большими данными рекомендуется проверить конвейер на небольшом искусственном файле. Каталоги с локальными данными и raw-результатами исключены из репозитория через `.gitignore`.
